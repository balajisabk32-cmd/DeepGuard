# `mediapipe>=0.10.0` on different days get different builds — and that range now
# resolves to 1.0.0, a major version whose API differs from every 0.10.x tutorial.
#
# Versions below marked (verified) were observed installed and working locally.
# The rest carry major-version caps only, because they were not resolvable offline.
#
# >>> AT T+0:45, ON THE FIRST MACHINE THAT FULLY INSTALLS: run `make lock`
# >>> (pip freeze > requirements.lock.txt), commit it, and have everyone install
# >>> from the lock file. This file states intent; the lock file is the contract.
